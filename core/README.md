# Core

Owns shared, cross-language contracts and platform-neutral foundations.

| Path | Ownership |
| --- | --- |
| `contracts/` | Canonical cross-language versions, errors, and RuntimeMessage framing. |
| `config/` | Strict read-only parsing and validation of the versioned product configuration. |
| `capability/` | Stable privacy-minimal capability types and native capability normalization. |
| `model-package/` | Reserved ownership boundary for a later validated model-package contract; no package behavior exists in Phase 0.5. |
| `telemetry/` | Reserved ownership boundary for Task 11 telemetry definitions; no logging implementation exists in Task 12. |
